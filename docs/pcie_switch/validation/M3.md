# M3 详细 FLIT 与周期模型验收记录

本轮验收覆盖 VC0、普通对齐 Memory TLP、单颗双向端点或有限级联
透明 Switch、已初始化链路，以及显式序号的 Standard Replay 子集。
性能使用合成端点，按下表分别判定数值目标。SimAI 接入属于 M4。

## 协议与资源正确性

| 检查 | 独立预期与实测 |
|---|---|
| V-06/10/13 | Requester/Tag 与 Byte Count/Lower Address 独立检查，分段读在末片后才归还 Tag；非法片不推进，终止错误归还 Tag。相同出口可提前预留 staging，提交仍按同一发射 FIFO 的顺序；跨出口仍等前序 TLP 物理发出。 |
| V-16 | Mem32/Mem64、CplD、带 OHC-A5 的错误 Cpl 字节 fixture；236/6/8/6 B 布局、跨 FLIT 组装、NOP、半区限制。首个不满 FLIT 等 flush deadline，已有满帧随后在可用 edge 连续发出。 |
| V-17 | Dedicated 回退，Shared 与合并池的分组、余量、VC usage 和归还；已初始化配置在原生路径生效，缺 Shared FC TX 能力在启动前拒绝。 |
| V-18 | 累计 ACK/NAK、1023→1 回卷、有限窗口、真实重发占线、同拍完成顺序与重复抑制。配对模式下 NOP ACK/NAK 和反向数据竞争，控制计独立 wire ticks 且不占数据序号或 replay 项。 |
| V-35 | 独立算例覆盖解析发行槽、读写 SRAM 拍、Fabric grant/释放、跨 Slice、双时钟 CDC、staging 和发射边界，见下节。 |

CRC 的八个输出字节与本地 Base Spec Appendix K.2 全部 1936 个
单输入 bit 的独立结果一致。FEC 用独立 6 B 槽和可配置延迟模拟；
单一可控位错用来验证 CRC/重放恢复。

| 原生场景 | 原发数据 FLIT | 重发数据 FLIT | 控制 FLIT | CRC 拒绝 | 重复抑制 | 超时 |
|---|---:|---:|---:|---:|---:|---:|
| 单颗 Shared / 合并 Shared，各自 | 24 | 0 | 0 | 0 | 0 | 0 |
| 两颗 Dedicated | 37 | 0 | 0 | 0 | 0 | 0 |
| 两颗首帧 CRC 错误，延迟回程 | 37 | 3 | 0 | 1 | 0 | 0 |
| 两颗首帧 CRC 错误，配对回程 | 37 | 4 | 40 | 1 | 0 | 0 |
| 单颗丢首 ACK、一格重放，延迟回程 | 26 | 1 | 0 | 0 | 1 | 1 |
| 单颗丢首 ACK、一格重放，配对回程 | 26 | 1 | 26 | 0 | 1 | 1 |
| 两颗 8→1、一格暂存 | 140 | 0 | 0 | 0 | 0 | 0 |

普通 FLIT 场景核对每跳四个 Write、两个 Read 和三个 CplD；8→1
恢复后每颗转发 56 个 TLP。暂停时捕获目标链路信用阻塞，结束时
等待图为空。所有场景校验 payload 字节、唯一完成与排空。每个数据
或控制 FLIT 的 256 B 串行化开销单独计数。

### V-35 周期合同

- 原生 2 ns link、1 ns core、两端各 2 个目标域 CDC 周期。
  首个短 Write 的 ingress / parse start / parse done / core ready /
  SRAM write / RX release / grant / read-lane release / Fabric done /
  egress ready / TX accept / TX depart 顺序为
  `39/40/42/44/45/46/46/47/47/52/53/56 ns`。
- 独立 6-tick link、10-tick core、7-tick 跨 Slice 传播验证两个
  时钟边沿取整；同端口 parser 容量 1 与 2 的发行分别为
  `[6,12]` 与 `[6,6]` tick。
- 144 B TLP（3 个 64 B Cell）以每周期 1 Cell 占用一条读写路径。
  写中间拍为 20/30 tick，40 归还 RX；读/Fabric 中间拍为
  60/70 tick，80 归还预约的读服务与通道，阻塞出口仍占 3 Cell。
  两个同出口 TLP 的 grant 为 20/30 tick，管线传播没有延长 bank
  占用；第三个跨出口同域 TLP 至前两笔离线才获准。
- 九端口在 3 个 Slice 内独立编址。跨 Slice 置换 `(i+3)%9`
  实测每条请求方向，以及 Read Completion 按 Requester ID 返回。
  反例把可同时 grant 的通道从 9 个降为 3 个，同样九路写流量的
  吞吐降为每路三分之一，符合整数授权容量。
- TDD Red 包含满帧被 flush 多延一个周期、反向 ACK 未占线、
  同出口串行等待、缺中间拍及尾延 trace 截断；修正后各自的预期
  周期、资源所有权和回归场景通过。

## V-23/24 性能与能力判定

独立分母使用 x16 单向 128 GB/s、`236/256` 的 TLP 区比例、
可对齐 TLP header 开销及显式端点服务 cut。吞吐用 1 μs 预热
和 3 μs 测量窗口，统计目的可见的 Posted payload 或已完整组装
的 Read payload；仅完成的应用请求进入分子。采集方向、类型、
TLP/FLIT 字节、控制/重发占线、core 服务拍和未完成请求。窗口端有
整笔请求切分误差，例如 4 KiB / 3 μs 约为 1.37 GB/s。所有
下表运行的数据正确性均通过。

| 目标 | 实测与判定 |
|---|---|
| P-01 | x16 每 1 ns 送 128 B，256 B 数据或控制 FLIT 各占 2 ns；九口 raw TX 预算 1152 GB/s。 |
| P-02 | 1 GHz，64/256 B 的单 TLP 路径核心边界同 Slice 10 ns、跨 Slice 12 ns，通过 100 ns 门槛。 |
| P-03 | 有各阶段和链路传播模型，欠缺 PHY/pin 标定，保持不可比。 |
| P-04 | RTT-64 的合成 Packet 提交至可消费为 53 ns，缺实际 PHY/端点预算，`NOT_COMPARABLE`。 |
| P-05 | 4 KiB 独立上限 112.716 GB/s。延迟回程 Write 113.323、Read 111.957，通过。Read 的 MRRS 512/4096 及 replay 16/64 格对照均为 111.957。配对回程 Write 113.323 通过，Read 99.669 未达 95%，控制与数据争用方向可见。 |
| P-06 | 单路 64 B Write 64.000/64.000 GB/s，八路 Write 每路 8.000/8.000，均通过。单路 Read 延迟回程 48.000/64.000、配对回程 45.995/64.000；八路合计 48.000/64.000、每路 0–13.888，未达标。热点下单路可能在窗口内无完成。 |
| P-07 | 九路 Write 同/跨 Slice 都是每路 64.000/64.000 GB/s，合计 576.000，跨 Slice 配对回程同样通过。三通道反例仅 192.000；九路 Read 合计 288.000，9 个 grant/cycle 要同时承接 Request 和 Completion，未达标。 |
| P-08 | 三个稳态窗口、9 路非过订阅 64 B Write，每流参考率 1/7 笔/ns，实际 0.1 笔/ns。两种回程配置均为空载 P99 12 ns、加载 P99 10 ns，各 10800 样本、零删失、队列无净增长，通过。 |
| P-09/10 | 广播与 INC/collective 收益待后续范围。 |
| P-11/12 | PPA 与 RAS SLA 缺业务数值。 |
| P-13 | 缺安全 C/T 与 pin 测量证据，保留为缺能力。 |

M3 在明确的能力范围内提供周期模型与目标评估。覆盖范围外包括
训练和动态 FC 初始化、完整 FC Update DLLP 编码/缩放、全面隐式
FLIT 序号/NAK 调度、Selective Replay、电气/FEC 行为和 pin 计时。
FC 归还仍采用协调更新事件，配对回程只对 ACK/NAK NOP 占线建模。
配对回程优先发送到期的累计控制 FLIT，未实现 payload 捎带 ACK。

## 复现入口

回归结果为 56 项 C++ GTest、38 项主机 Python 测试及 27 个
NULL/fast TestLib 场景（54 项检查）全部通过。Shared TX 能力
负例按预期在配置时失败，26 组性能场景的数据正确性全部通过。

- `tests/gem5/pcie` 的 NULL/fast 套件运行链路、故障、周期与置换
  fixture，保存 `flit-result.json`、`cycle-trace.json` 和
  `incast-result.json`。
- `build/NULL/gem5.fast -d /tmp/m3-perm configs/example/pcie/performance.py SW-PERM --write --wire-feedback`
  输出 profile、独立分母、源文档 SHA-256 和每方向窗口计数。
  同一入口支持 SW-LAT、RTT-64、SW-BULK、SW-SMALL 和扰动选项。
- `python3 configs/example/pcie/tail_latency.py build/NULL/gem5.fast /tmp/m3-tail`
  输出两个 cohort 的原始报告和 `tail-result.json`。
