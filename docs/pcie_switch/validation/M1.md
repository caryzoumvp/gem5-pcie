先固定 HTML 的 sizing、JSON 和 bench oracle。Sizing 空实现的 15 个
子例失败，计算实现后相同子例通过。CLI 交换功能添加前的 8 个导入/
导出及拒绝子例失败，实现后通过。非默认 seed 往返测试也捕获了默认值
覆盖，再校验修正后的同一测试。事件基准由页面 `runBench` 内实际 diff
及 `simulateHardware` 生成，生成器只抽取锁定 HTML 的相关代码。
TestLib checker 自测将七个成功结果的完成计数各改大 1，七个变体都
在具体场景的 `sim.stats.completed` 路径报错。

参考事件保留 HTML 浮点 ns 截止时间与 heap 平局顺序，每个回调用 gem5
主队列在向上取整的 ps tick 调度。对照要求计数和整数状态精确相同，
浮点相对容差为 `1e-12`，绝对容差为 `1e-10`。延迟从首条 Link 发射
到本请求完成，带宽按完成 payload、前 20% 预热后的窗口及发起端口数计算。

复现命令从仓库根目录执行：

```sh
python3 -m unittest discover -s tests/pcie_switch -p 'test_*.py'
node tests/pcie_switch/fixtures/generate_reference_events.js
mkdir -p /tmp/pcie-m1-system-protobuf
ln -sf /usr/lib/x86_64-linux-gnu/libprotobuf.so /tmp/pcie-m1-system-protobuf/
PROTOC=/usr/bin/protoc LINKFLAGS_EXTRA=-L/tmp/pcie-m1-system-protobuf \
    scons build/NULL/gem5.fast -j 16
./tests/main.py list tests/gem5/pcie -q --suites --isa=NULL --variant=fast
./tests/main.py run tests/gem5/pcie --isa=NULL --variant=fast --skip-build
git diff --check
```
